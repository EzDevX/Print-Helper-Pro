# Changelog

All notable changes to PrintHelper Pro will be documented here.

## [0.1.0-alpha] - Initial Alpha Release

### Added
- Initial Windows Forms application.
- Multiple PDF file selection.
- PDF page count display.
- Printer selection.
- A3 and A4 paper size options.
- Portrait and Landscape orientation.
- Color and Black and White printing.
- One-Sided and Double-Sided printing.
- Long Edge and Short Edge options.
- N-up printing with 1, 2, and 4 pages per sheet.
- pdfcpu integration.
- PdfiumViewer integration.

### Known Issues
- Limited error handling.
- Temporary PDF files are not automatically deleted.
- N-up settings may not be applied correctly to subsequent files in a multi-file queue.

### Development Status
Early Alpha. Active development continues.
